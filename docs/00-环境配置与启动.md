# 环境配置与启动指南

## 1. 获取代码

```bash
# 比赛代码（主控 + 任务 1-6）
cd /home/cyberdog_sim/src
git clone https://github.com/HarryGit-HUST/little_rice_dog.git my_race_code

# 底层工具箱（move、tts、stage2、sub_main_control 等）
cd /home
git clone https://github.com/RgerColdline/cyberdog_utils.git
```

## 2. 安装依赖

```bash
# Python 包
pip3 install lcm toml edge-tts certifi opencv-python numpy

# 系统包
apt-get update
apt-get install -y pulseaudio-utils mpg123 alsa-utils tmux
```

## 3. 编译

```bash
cd /home/cyberdog_sim/src/my_race_code
colcon build

source /opt/ros/galactic/setup.bash
source /home/cyberdog_sim/install/setup.bash
```

## 4. 音频配置（容器内）

如果 `speak_blocked("测试")` 没声音，执行：

```bash
# 启动 PulseAudio 并加载真实声卡
pulseaudio --start
sleep 2
pactl load-module module-alsa-card device_id=2
pactl set-default-sink alsa_output.2.analog-stereo
pactl set-sink-volume alsa_output.2.analog-stereo 50%

# 验证
python3 /home/cyberdog_utils/tts/example_speak.py "测试"
```

> 每次容器重启后需重新执行。也可以加到 `~/.bashrc` 里自动启动。

## 5. 启动比赛

```bash
cd /home/cyberdog_sim/src/my_race_code
bash launch/start_all.sh
```

tmux 会自动创建 5 个终端窗口：

| 窗口 | 内容 | 说明 |
|------|------|------|
| 0 | Gazebo 仿真 | race_gazebo 物理世界，paused=false |
| 1 | 小脑控制 | cyberdog_control LCM-ROS 桥接 |
| 2 | 位姿广播 | `/pose` 话题 |
| 3 | 视觉节点 | 黄线检测 `/perception/yellow_line` |
| 4 | 主控大脑 | 任务 1→2→3→4→5→6 顺序执行 |

## 6. 单独测试某个任务

前提：Gazebo + cyberdog_control + pose_broadcaster 已启动（tmux 窗口 0/1/2）。

```bash
source /opt/ros/galactic/setup.bash
source /home/cyberdog_sim/install/setup.bash
cd /home/cyberdog_sim/src/my_race_code/race_core/race_core

# 传送狗到任务起点，然后运行
gz model -m robot -x 2.1 -y 7.3 -z 0.5 -Y 1.5708
python3 test_task4.py

# 测试任务五六串联
gz model -m robot -x 3.1 -y 7.3 -z 0.5 -Y -1.5708
python3 test_task56.py

# 测试任务四五六串联
gz model -m robot -x 2.1 -y 7.3 -z 0.5 -Y 1.5708
python3 test_task456.py
```

## 7. 路径与话题适配

### 7.1 cyberdog_utils 位置

所有代码硬编码了 `/home/cyberdog_utils`。如果你放在别处，需要改以下文件中的 `sys.path.append('/home/cyberdog_utils')`：

| 文件 | 行 |
|------|-----|
| `race_core/main_brain.py` | `sys.path.append('/home/cyberdog_utils')` |
| `race_core/task2.py` | 同上 |
| `race_core/task4.py` | 同上 |
| `race_core/task5.py` | 同上 |
| `race_core/task6.py` | 同上 |
| `race_core/test_task4.py` | 同上 |
| `race_core/test_task56.py` | 同上 |
| `race_core/test_task456.py` | 同上 |
| `launch/start_all.sh` | `UTILS_DIR="/home/cyberdog_utils"` |

### 7.2 Gazebo 话题名

不同 Gazebo 版本的 model_states / link_states 话题前缀不同（可能带 `/gazebo/`）。如果启动后 BallChaser 报 "5 秒内未收到 model_states"，先确认实际话题：

```bash
ros2 topic list | grep -E "model_states|link_states"
```

根据输出修改以下文件中的订阅话题名：

| 文件 | 订阅行 | 当前值 |
|------|--------|--------|
| `cyberdog_utils/race/stage2/vision.py` | `create_subscription(LinkStates, ...)` | `/gazebo/link_states` |
| `cyberdog_utils/sub_main_control/ball_chaser.py` | `create_subscription(ModelStates, ...)` | `/gazebo/model_states` |
| `cyberdog_utils/gazebo/scripts/pose_broadcaster.py` | `create_subscription(ModelStates, ...)` | `/gazebo/model_states` |

> 如果 `ros2 topic list` 显示不带 `/gazebo/` 前缀（如 `/model_states`），把上面三处的 `/gazebo/` 去掉即可。

## 8. 常见问题

| 症状 | 原因 | 解决 |
|------|------|------|
| `No module named 'rclpy'` | ROS2 未 source | `source /opt/ros/galactic/setup.bash` |
| `No module named 'move'` | cyberdog_utils 路径不对 | 参考 7.1 节修改路径 |
| TTS 生成成功但没声音 | PulseAudio 未启动或声卡未加载 | 执行第 4 步音频配置 |
| 狗不响应指令 | cyberdog_control 未运行 | 检查 tmux 窗口 1 |
| `/pose` 收不到数据 | pose_broadcaster 未启动 | 检查 tmux 窗口 2 |
| BallChaser 收不到球位置 | model_states 话题名不对 | 参考 7.2 节修改话题名 |
